# Remove DSL `title`; derive titles from `summary`; simplify description override

## Goals

1. Remove the `title` field from the `.api2ai` DSL grammar.
2. Derive MCP tool **titles** from `summary` with a consistent fallback chain:
   `DSL summary` → `OpenAPI summary` → `operationId` → `toolName`.
   Falsy/empty values at each step fall through to the next.
3. Make the **description** override semantics explicit and uniform:
   any DSL value (including empty `""`) always wins over OpenAPI; OpenAPI text
   is only used when the DSL `description` is **unset** (`undefined`).
   - DSL `description: ""` → suppresses the `API:` section entirely.
   - DSL `description: "…"` → used verbatim (trimmed) as the `API:` section text.
   - DSL `description` omitted → OpenAPI `description` is used iff truthy.

### CLI / codegen
- `packages/cli/src/openapi-tool-codegen.ts`
  - Update `buildMcpTitle(operation, details)`:
    - Use `operation.summary` (trim), else `details.summary` (trim if truthy),
      else `details.operationId` (trim if truthy), else `operation.toolName`.
    - Drop the `operation.title` branch.
  - Refactor description helper to make the override rule explicit:
    ```ts
    function pickEffectiveText(dslValue: string | undefined, openApiValue: string | undefined): string | undefined {
        if (dslValue !== undefined) {
            const trimmed = dslValue.trim();
            return trimmed.length === 0 ? undefined : trimmed;
        }
        const apiTrimmed = openApiValue?.trim();
        return apiTrimmed && apiTrimmed.length > 0 ? apiTrimmed : undefined;
    }
    ```
    Then use it inside `effectiveLongDescription` (and `buildMcpDescription`).

  - No structural change; still calls `buildMcpTitle` + `buildMcpDescription`.
  - The emitted `GeneratedTool` type still carries `title` (it’s the MCP-side

## Exact grammar change

```langium
Operation:
    method=HttpMethod path=STRING '{'
        'toolName' ':' toolName=STRING
        'intent' ':' intent=STRING
        ('example' ':' example=STRING)?
        ('summary' ':' summary=STRING)?
        ('description' ':' description=STRING)?
    '}';
```

(Removed the `('title' ':' title=STRING)?` line.)
